# 提示词文件（可直接复制粘贴）

每个 `.txt` 是一份**完整、独立**的提示词，打开后 `Ctrl+A` / `Ctrl+C` 全选复制即可。
完整套件（含里程碑说明、追问模板、跑偏对照表、自查清单）见 [`../CYBER_ARENA_PROMPTS.md`](../CYBER_ARENA_PROMPTS.md)。

| 文件 | 对应里程碑 | 约 token | 什么时候贴 |
|---|---|---|---|
| `P0.txt` | 项目宪法（约束，非任务） | ~1.0k | **每次新会话开头** |
| `P1.txt` | M0 企业门户靶场 | ~1.7k | P0 之后 |
| `P2.txt` | M1 WAF + 确定性攻击链（不接 AI） | ~2.2k | P1 测试全绿后 |
| `P3.txt` | M2 DeepSeek 三 Agent | ~1.7k | P2 闭环跑通后 |
| `P4.txt` | M3 包装与求职材料 | ~0.7k | P3 真实演练跑通后 |

## 开场模板

一条消息里先发这段，再贴 `P0.txt` 和本轮对应的 `Pn.txt`：

```text
下面 P0 是项目约束，P1 是本轮任务。严格按 P0 的交互规则执行：
先只给我「变更计划 + 文件树 + 接口契约表 + 测试清单」，
我确认之后你再写代码，一次给一个文件。

<P0 全文>

<P1 全文>
```

## 三条注意事项

1. **网页版模型**（ChatGPT / Claude 网页）摸不到你的磁盘，开头补一句：
   「你无法访问我的文件系统，需要哪个文件我会贴给你，不要假装读过我的仓库。」
   另外它跑不了 pytest，验收命令要你自己在本地跑，把报错贴回去。
2. **长会话会失忆**：聊到 5~6 轮以后，模型开始忘记 P0 的红线（尤其"零新增依赖""禁止 eval"）。
   每个里程碑中途重贴一次 `P0.txt`，或者干脆把它塞进自定义指令 / `AGENTS.md`。
3. **一次只做一个里程碑**。模型想多做就回：「只做当前里程碑，其余写进 PLAN.md。」

## 推荐组合

- 本地 Agent（DSH / Claude Code / Cursor / Codex CLI）：把 `P0.txt` 存成仓库根的 `AGENTS.md`，效果最好——它能自己读代码、跑测试。
- 网页版：P0 + Pn 一条消息发完，然后老老实实一轮一个文件。
